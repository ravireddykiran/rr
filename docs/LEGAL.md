# Legal

This repository contains **no video**. It contains:

- links to live streams that broadcasters publish openly on the internet (free-to-air networks, public broadcasters, FAST channels such as Pluto TV / Plex / Rakuten, news networks' own web streams), collected by the [iptv-org](https://github.com/iptv-org/iptv) community and released under CC0;
- a script that re-downloads that index and formats it as playlists;
- a web player and configuration for free, open-source apps (hls.js, Jellyfin, nginx).

It deliberately does **not** include pirated pay-TV, Xtream-Codes resellers, "premium" sports packages or anything that needs a cracked login. If you find a link here that infringes your rights, open a copyright-claim issue with iptv-org at https://github.com/iptv-org/iptv/issues and it will drop out of the next rebuild automatically.

Some streams are geo-restricted by their owners; the playlists label them "Geo-blocked". Respect those restrictions and your local laws.

Code in this repository: MIT. Channel data: CC0 (iptv-org). hls.js: Apache-2.0 (see `player/hls.LICENSE`).
